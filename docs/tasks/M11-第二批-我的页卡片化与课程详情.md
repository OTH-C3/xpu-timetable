## 一、我的页卡片化（参照小黑盒/QQ 设置页）

**现状**：`ui/settings/SettingsRows.kt` 的 `SettingsRowShell` 只画发丝分隔线，分组之间无容器。
**改法**：
1. `SettingsRows.kt` 新增 `SettingsGroupCard(content)`：圆角 12dp 容器
   （背景 `colorScheme.surfaceContainerLow`、发丝边框 `outlineVariant @ 12%`），
   组内条目之间画横线（`outlineVariant @ 12%`，不满宽——左右缩进 16dp）；
2. `SettingsRowShell` 的分隔线改为"不满宽"（与卡片内横线一致）；
3. `SettingsScreen` 里每个分组（学期 / 权限 / 数据 / 关于）包一层 `SettingsGroupCard`，
   组标题保留在卡片外（参照两张截图：标题在卡片上方、灰色小字）。
**验收**：分组之间有可辨识的卡片边界；组内横线不满宽；深浅主题都检查；
触摸目标仍 ≥44dp；单文件行数不破门禁。

## 二、课程详情改为底部弹层（参照图：课表 → 点课程卡）

**现状**：点课程卡直接进 `CourseEdit` 编辑页。
**改法**：
1. 新增 `ui/timetable/CourseDetailSheet.kt`：底部弹层（半透明遮罩 + 圆角上沿面板），
   内容 = 课程色竖条 + 课名、周数（"第 2-2 周, 第 6-6 周…"格式化）、节数与时间
   （用 `TimeSlot` 换算）、教室、教师、备注（可编辑框 + 「仅本周 / 所有周」切换）、
   底部三个动作：编辑 / 复制 / 删除；
2. `TimetableScreen` 点课程卡 → 弹出该弹层（不进导航栈；返回键 = 关闭弹层，走 BackHandler）；
   弹层里「编辑」→ `onEditCourse(courseId, sessionId)` 进编辑页（现状不变）；
3. 「复制」= 生成同课程新 session（保存走 `upsertCourse`，courseId 新建）；
   「删除」沿用删除确认流程；
4. 备注字段：`courses.note` 已存在 ✓，仅本周/所有周只影响备注显示与否（数据模型不变）。
**验收**：弹层从底部滑入 300ms、点遮罩/返回关闭；编辑/复制/删除三个动作都可用；
弹层内容与点的那张卡一致；不破坏 M10 的转场方向。

## 三、增加课程页重做 + 颜色选择器（参照图：课程/日程切换 + HSV 取色）

**现状**：`CourseEditScreen` 是普通表单；颜色只有 `colorTag` 离散色。
**改法**：
1. 顶部结构改为「关闭(×) | 课程/日程 两个 tab | 保存」，标题区一张大卡片（课程名输入 +
   颜色行 + 学分行）；
2. 「时段」分组卡片：周数 / 节次 / 自定义时间 / 教室 / 老师 / 备注（每行带图标 + 右箭头或值），
   卡片头右侧「复制 / 删除」；
3. **颜色选择器**（不引第三方库，自绘 Compose）：
   - `ui/courseedit/components/ColorPickerDialog.kt`：
     `Box` 上用 `Canvas` 画 HSV 的 S×V 平面（饱和度横向、明度纵向，色相固定）；
     右侧色相条（0..360 竖条）；拖拽用 `pointerInput { detectDragGestures }`；
     底部显示当前色块 + `#RRGGBB` 文本框（可手输，解析失败不改色）；
     「取消 / 保存」两个文字按钮；
   - 色值 ↔ `colorTag`：当前 `CoursePalette` 是离散色，需要扩展为
     **保存 `Color` 的 ARGB int**（`courses.color_tag` 是 Int，直接存 ARGB ✓）；
     `CoursePalette.base(tag)` 需兼容两种取值（旧：0..N 离散索引；新：ARGB int）——
     约定：tag < 100 视为离散索引，否则视为 ARGB（二进制安全：离散色不足 100 个）。
**验收**：取色盘拖动流畅（60fps 目标，`Canvas` 只在拖动时重绘）、hex 手输生效、
保存后课程卡与小组件竖条颜色一致（同一 color_tag）；旧数据的离散色继续正常显示。

## 四、课表左侧备忘录（需求文字较模糊，按以下解读实现）

**解读（默认假设，如不符请纠正）**：在课表页左侧**节次时间轴的最上方**（"1"的上方）
放一个「备忘录」入口，点开是一张便签卡片（每学期一条，内容随 `Term` 存）；
不做独立的备忘录列表页。
**改法**：
1. `terms` 表加一列 `memo TEXT NULL`（Room 迁移 +1 版本，`fallbackToDestructiveMigration` 不许用——
   项目有真实数据）；
2. 时间轴列顶部画「备忘录」小字入口 → 点开 `AlertDialog`（多行输入 + 保存/清除）；
3. 有内容时入口上方显示 memo 前 8 字预览。
**验收**：老库升级不丢数据；memo 保存后重进 App 仍在；入口不遮挡第 1 节。

## 五、设置里增加「显示老师姓名」开关

**现状**：课程卡不显示教师；DataStore 依赖还在但 `data/prefs/` 已删。
**改法**：
1. 新建 `data/prefs/UiPrefs.kt`（DataStore<Preferences>，key `show_teacher`，默认 **true**）；
2. `AppContainer` 暴露；`TimetableViewModel` 暴露 `showTeacher: StateFlow<Boolean>`；
3. `WeekGrid`/`CourseCard` 增加 teacher 行（教室行之后，`@教师名`）；
4. 「我的」→「数据」组内加一行「显示老师姓名」+ Switch（写入 UiPrefs）。
**验收**：开关切换后课程卡立即增减教师行（不重启）；默认开启；开关状态重启后保持。
