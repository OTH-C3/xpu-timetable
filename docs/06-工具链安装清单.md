# 工具链安装清单 — 西工程大课表

> 生成日期：2026-09-16
> 目标机器：**CachyOS（Arch 系）Linux**，shell 为 **fish**
> 验收标准：`java -version` / `adb version` / `sdkmanager --list_installed` 三项通过，且 Android Studio 能创建并同步一个 Compose 项目
> 本清单只做「环境安装」，不含项目代码。

---

## 0. 一句话说明

在 CachyOS 上装齐 **JDK 21 + Android Studio + Android SDK（含 platform 37）+ git + adb udev 规则** 四类东西即可；Gradle 不用单独装（项目用 Wrapper）。**没有 sudo 也能装**（见路线 B）。

## 3. 路线 A：系统级安装（有 sudo，最省事，推荐）

```bash
# 0) 确认已启用 multilib 仓库（64 位系统装 32 位依赖库时需要，否则报 target not found: lib32-*）
#    编辑 /etc/pacman.conf，取消 [multilib] 段注释后：sudo pacman -Sy

# 1) 基础工具与 JDK 21
sudo pacman -S --needed base-devel git jdk21-openjdk

# 2) 把默认 Java 切到 21（Arch 多版本共存时必需）
sudo archlinux-java set java-21-openjdk
java -version      # 期望：openjdk version "21.x"

# 3) Android Studio 与 adb udev 规则（AUR，需 yay/paru 等 AUR helper）
paru -S --needed android-studio android-udev

# 4) 启动 Android Studio（首次会跑 Setup Wizard）
android-studio
```

**SDK 安装（两种任选）**

- **推荐：由 Android Studio 管理**——首次启动向导或 `Settings → Languages & Frameworks → Android SDK` 勾选：
  - SDK Platforms：**Android API 37**（勾选 Show Package Details 以确认）
  - SDK Tools：**Android SDK Platform-Tools**、**Android SDK Build-Tools**（默认版本即可）
  - 可选：Android Emulator + 一个 System Image
  默认 SDK 路径：`~/Android/Sdk`
- **命令行方式**：用 AS 自带 SDK 目录下的 `cmdline-tools/latest/bin/sdkmanager` 执行：
  ```bash
  sdkmanager "platform-tools" "platforms;android-37.0" "build-tools;36.0.0"
  sdkmanager --licenses     # 全部输入 y 接受
  ```

## 4. 路线 B：用户级安装（无 sudo / 不想动系统）

```bash
# 1) JDK 21（Temurin 官方 tarball，用户级）
mkdir -p ~/opt && cd ~/opt
curl -L -o jdk21.tar.gz "https://api.adoptium.net/v3/binary/latest/21/ga/linux/x64/jdk/hotspot/normal/eclipse"
tar -xzf jdk21.tar.gz && rm jdk21.tar.gz
export JAVA_HOME=~/opt/$(ls -d jdk-21* | head -1)

# 2) Android 命令行工具（已实测该地址可达）
mkdir -p ~/Android/Sdk/cmdline-tools && cd ~/Android/Sdk/cmdline-tools
curl -L -o cmdtools.zip "https://dl.google.com/android/repository/commandlinetools-linux-13114758_latest.zip"
unzip -q cmdtools.zip && mv cmdline-tools latest && rm cmdtools.zip
# 若无 unzip：python3 -c "import zipfile;zipfile.ZipFile('cmdtools.zip').extractall('.')"

# 3) 装 SDK 组件并接受许可
export ANDROID_HOME=~/Android/Sdk
~/Android/Sdk/cmdline-tools/latest/bin/sdkmanager "platform-tools" "platforms;android-37.0" "build-tools;36.0.0"
~/Android/Sdk/cmdline-tools/latest/bin/sdkmanager --licenses

# 4) Android Studio（官方 tarball，解压即用，无需 root；当前稳定版 2026.1.3.8）
mkdir -p ~/opt && cd ~/opt
curl -L -o as.tar.gz "https://dl.google.com/dl/android/studio/ide-zips/2026.1.3.8/android-studio-quail3-patch1-linux.tar.gz"
tar -xzf as.tar.gz && rm as.tar.gz
~/opt/android-studio/bin/studio.sh

# 5) git（若系统无 git 且无 sudo：请用发行版自带包管理器安装，或从 https://git-scm.com/download/linux 获取静态构建）
```

## 5. 环境变量（fish 为主，附 bash 版）

**fish**（写入 `~/.config/fish/config.fish`，或直接用 `set -Ux` 持久化）：

```fish
set -Ux JAVA_HOME /usr/lib/jvm/java-21-openjdk        # 路线 B 改为 $HOME/opt/jdk-21.x.y
set -Ux ANDROID_HOME $HOME/Android/Sdk
set -Ux ANDROID_SDK_ROOT $HOME/Android/Sdk
fish_add_path $ANDROID_HOME/platform-tools $ANDROID_HOME/cmdline-tools/latest/bin
```

**bash / zsh**（`~/.bashrc` / `~/.zshrc`）：

```bash
export JAVA_HOME=/usr/lib/jvm/java-21-openjdk
export ANDROID_HOME="$HOME/Android/Sdk"
export ANDROID_SDK_ROOT="$ANDROID_HOME"
export PATH="$PATH:$ANDROID_HOME/platform-tools:$ANDROID_HOME/cmdline-tools/latest/bin"
```

## 7. 资源与注意事项

- **磁盘**：Android Studio + SDK + Gradle 缓存 + 依赖 ≈ **8–15GB**（AS 每个大版本 IDE 缓存另占 ~2GB）。当前 home 分区余量 139GB，充足。
- **内存**：本机 15GiB。**建议真机调试优先**：模拟器额外占 2–4GB，与 Gradle 守护进程并发时偏紧。
- **首次构建需联网**：Gradle Wrapper 会下载 Gradle 发行版与全部依赖（数百 MB）。
- **Wayland 会话下模拟器**：手装 tarball 时模拟器可能因 Qt 平台插件报错；AUR 包的桌面项已设 `QT_QPA_PLATFORM=wayland;xcb` 规避。用真机可完全绕开此问题。
- **JDK 选 21（LTS）**：不建议装最新非 LTS 的 `jdk-openjdk`，与 Gradle / Kotlin 组合的兼容性未经本项目验证。
- **4 项版本【核对】条目**（KSP 构建号、Navigation 3 patch、Glance 1.2.0、coroutines patch）在首次 `gradle sync` 时按报错修正，属正常流程。

5. 是否安装了模拟器（影响后续验收方式选择）
