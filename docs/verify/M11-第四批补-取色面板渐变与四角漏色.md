## 二、渐变：马赛克 → 连续渐变

### 改前
- S×V 平面：`STEPS = 20`，按 `GridCell` 切成 20×20 = 400 个小方块，每格一个纯色值。
  看起来就是"只有这几档颜色"。
- 色相条：切成 6 段 `Color`，段与段之间是硬边。

### 改后
两层 Brush 叠出标准 HSV 平面，**恒定两次 drawRect**，不随 hue 变而在-off 路径上重复计算：

```kotlin
val pure = Color(ColorPickerMath.hsvToArgb(hue, 1f, 1f))
drawRect(brush = Brush.horizontalGradient(listOf(Color.White, pure), 0f, size.width))
drawRect(brush = Brush.verticalGradient(listOf(Color.Transparent, Color.Black), 0f, size.height))
```

- ① 横向 白 → 当前色相最纯色，把饱和度从 0 铺到 100%（左端恒为白）
- ② 纵向 透明 → 黑，把明度从 100% 压到 0%（下端恒为黑）

色相条改 7 停靠点连续渐变，`0/60/…/360`，**首尾都是红**（色相是环，360° 与 0° 同色，条子才首尾接得上、不露接缝）。

### 踩过的坑
⚠️ 带停靠点的重载是 `vararg`：

```kotlin
// 错：位置传参会把 Array<Pair> 匹配到 List<Color> 那个重载上 → None of the following candidates is applicable
Brush.verticalGradient(HUE_STOPS.toTypedArray(), 0f, size.height)
// 对：展开符 + 具名参数
Brush.verticalGradient(*HUE_STOPS.toTypedArray(), startY = 0f, endY = size.height)
```

已删除：`GridCell` / `buildGrid` / `STEPS` / `key(hue)` 包裹 / HueSlider 的 `bars` 与 6 段 for 循环。

## 三、四角三角形：定性 → 定位 → 删掉

### 3.1 先排除"是我们画的"这一可能

| 检索范围 | 关键词 | 结果 |
| --- | --- | --- |
| `app/src/main/java` 全部 kt | `triangle` / `polygon` / `trigon` | 0 命中 |
| `app/src/main/res` 全部 drawable / xml / layout | `triangle` / `polygon` | 0 命中 |
| `AppIcons.kt`（Lucide 图标库） | `triangle` | 0 命中 |
| git 全历史 `rev-list --all`（19 次提交）`git grep -i triangle` | `triangle` | 0 命中 |

结论：**代码里从来没有画过三角形**，它是渲染产物，不是装饰。

### 3.2 像素定位（肉眼看 1px 差异不可靠，改用取色判定）

扫描得到平面包围盒 `x[183,802] y[763,1381]`，即 620×620 正方形。
`ListRow.CardCorner` 在 3x 密度下约 84px。

判据：取整角内侧 2px 的点 `(184,1381)` —— 它是**纯黑 `(2,2,2)`**（渐变实色）；
而它相对圆角圆心 `(267,1298)` 的距离是 `√(83² + 83²) = 117.4 > 84`，**落在圆角外面**。

### 3.3 根因

```
.border(1.dp, outlineVariant, RoundedCornerShape(CardCorner))   ← 描边是【圆角】
Canvas { drawRect(brush = ...) }                                 ← 填充是【直角】
```

两者形状不齐：`Canvas` 不受 shape 约束，铺的是方块；渐变从圆角弧**外面**戳出去，
每角漏一块实色小三角。底下两角黑对浅灰最扎眼，上面两角左边是白（看不见）、右边是深红（能看见）——四个角，与老大所见一致。

**它没有任何功能**，纯属不同形状叠出来的产物。

### 3.4 修法与同类排查

给 `HueCanvas` / `HueSlider` 各补一行 `.clip(shape)`（和 border 用**同一个** shape）。

全项目排查，其余 `border()` 处本来都配了 `clip`，只有本文件漏了：

| 文件 | border | clip |
| --- | --- | --- |
| `ui/components/CardGroup.kt` | 有 | 有 |
| `ui/timetable/components/CourseCard.kt` | 有 | 有 |
| `ui/courseedit/components/FormControls.kt` | 有 | 有 |
| `ui/courseedit/components/ColorField.kt` | 有 | 有（CircleShape） |
| **`ColorPickerDialog.kt`** | 有 | **漏 → 已补** |

新增项目级纪律：**`border(圆角 shape)` 必须配 `.clip(同一个 shape)`**。
