# ADR-009: 版本基线修正 — compileSdk 37 / targetSdk 36 / Kotlin 2.3.21

- **Status**: Accepted (2026-09-16)
- **Date**: 2026-09-16
- **Deciders**: 项目维护者
- **Supersedes / Amends**: Phase 0 报告《01-开发环境与教务对接分析.md》§2 与 §3 中的部分版本锚定（修订关系见下）
- **Related ADRs**: 全部（本 ADR 是其余选型的版本前提）

## Background

Phase 0 报告（2026-09-16 编制）在 §2/§3 锚定了：Compose BOM 2026.08.00、compileSdk / targetSdk 36、Kotlin 2.2.x（"以 AS 新建项目模板为准"）。该报告同时声明"版本号以调研当日官方页面为准，标注『待验证』处需在 Phase 1 复核"——本 ADR 即该复核的结果。

复核时间：2026-09-16（联网核实官方发布页）。

### 核实发现的冲突（强证据）

1. **Compose BOM 2026.08.00 与 compileSdk 36 不可兼得。**
   Compose 2026 年 8 月版发布说明明确：核心模块升至 1.12，**compileSdk 更新至 API 37，要求 AGP 最低 9.1.2**（原文："Compose 1.12 updates compileSdk to API 37, requiring a minimum AGP 9.1.2"）。Android 17（API 37）SDK 已于 2026-06 正式发布，官方 SDK 设置文档给出 `compileSdk = 37`。
   来源：developer.android.com 博客「What's new in the Jetpack Compose August '26 release」；Compose BOM 使用文档；Android 17 设置 SDK 文档。

2. **Kotlin 2.2.x 已过支持窗口，且无法消费当前 serialization。**
   Kotlin 官方版本页：2.2.21（2025-10-23）是 2.2 系最后版本；2.3.0 于 2025-12 发布，2.3.21 于 2026-04 发布，2.4.x 于 2026-06 起发布。kotlinx-serialization 变更记录：1.10.0 起基于 Kotlin 2.3 编译（1.11.0 基于 Kotlin 2.3.20），Kotlin 2.2 项目消费时元数据版本不兼容。
   来源：kotlinlang.org 版本页与 release history；kotlinx.serialization 变更记录（1.10.0 / 1.11.0）。

3. **Hilt / Dagger 生态基线已到 Kotlin 2.3.21。**
   com.google.dagger:hilt-android 2.60.1（2026-07-06）记录"Updated Kotlin version to 2.3.21"。（本项目未采用 Hilt，见 ADR-004，但该事实进一步佐证 2.3.x 是当前生态基线。）
   来源：mvnrepository / maven central 的 hilt-android 版本记录与 2.60 变更日志。

## Decision

对 Phase 0 基线做如下修订（最终锚定见架构文档 §4.1）：

| 项 | Phase 0 记录 | 本 ADR 修订为 | 依据 |
|----|--------------|---------------|------|
| compileSdk | 36 | **37（Android 17）** | Compose 1.12 强制；Android 17 SDK 已发布 |
| Kotlin | 2.2.x | **2.3.21** | 2.2 系支持窗口结束；serialization 1.10+ 要求 Kotlin ≥ 2.3 |
| targetSdk | 36 | **维持 36**（不跟到 37） | 见下方决策理由 |
| minSdk | 26 | **维持 26** | 无冲突，Phase 0 决策有效 |
| Compose BOM | 2026.08.00 | **维持 2026.08.00** | 与 compileSdk 37 组合自洽 |
| AGP | 9.3.0 | **维持 9.3.0** | 满足 Compose 1.12 的 ≥9.1.2 要求 |
| Gradle | 9.x | **维持 9.x（须 ≥ 9.1）** | AGP 9 要求 |

### 为什么 targetSdk 维持在 36 而不是一并跟到 37

targetSdk 的抬升会**选择加入** Android 17 的运行时行为变更，其中两条与本项目直接相关：

1. **证书透明度（CT）默认启用**：target 37 后 CT 校验强制生效。本项目主要网络通路是 WebView 访问学校站点，若学校站点证书链存在非公共 CA 等不规范情形，target 37 会引入连接失败风险——这类失败发生在用户侧、且难以在我们这边复现与修复。
2. **本地网络默认隔离 / 大屏可调整性强制等**：本项目虽不受影响或有替代路径，但首版没有为这些行为变更建立测试计划的必要。

GitHub 直分发不受 Play 商店"新应用与更新须 target API 36 及以上"约束（该约束当前正以 API 36 为门槛），因此维持 36 没有分发风险。**升级 targetSdk 37 列为 v1.1 的独立验证任务**：在真机验证学校站点 CT 行为与全部主流程后再抬升，届时同步更新本 ADR 与架构文档。

## Consequences

### 正面

- 版本组合自洽：Compose 1.12 ↔ compileSdk 37 ↔ AGP 9.3 ↔ Gradle 9.x ↔ Kotlin 2.3.21 ↔ kotlinx-serialization 1.11.0 ↔ Room 3.0.3，全部经官方发布页/仓库核实，消除 Phase 0 遗留的版本矛盾。
- 语言线处于受支持状态（Kotlin 2.3 系），避免新项目起步即踩 EOL 线。
- targetSdk 保守取值优先保证"能连上学校站点"这一核心可用性，把未知风险推迟到有真机验证条件的版本。

### 负面 / 代价

- compileSdk 提升到 37 意味着开发者需安装 Android 17 SDK（Build-Tools 37），首次环境准备比 Phase 0 预期多一步（AS 的 SDK Manager 操作）。
- 使用 compileSdk 37 时会面临 Android 17 对**所有应用**生效的行为变更提示（如动态代码加载加固等），本项目不涉及动态加载，实际影响为零，但需在构建期确认无 lint 阻断项。
- Kotlin 2.3.21 与 Compose 编译器插件必须严格同版，Kotlin 升版时 Compose 编译插件随之升级；KSP 具体构建号需与 Kotlin 2.3.21 配对（首次构建时按 KSP 发布页核对，见架构文档 §4.3）。
- 与 Phase 0 报告的差异若不显式同步，会造成团队文档不一致（见下方"对 Phase 0 文档的修订关系"）。

### 对前期文档的修订关系

- 本 ADR **修订**（不是推翻）Phase 0 报告《01-开发环境与教务对接分析.md》的以下内容：
  - §2 表格中"Kotlin 2.2.x（以 AS 新建项目模板为准）"→ 应更新为 **Kotlin 2.3.21**，并补注"kotlinx-serialization 1.10+ 要求 Kotlin ≥ 2.3；Kotlin 2.2 系支持窗口已结束"；
  - §3 表格中 compileSdk 36 → **37**，理由列为 Compose 1.12 强制（BOM 2026.08.00 发布说明）；targetSdk 保持 36 不变，但应补注"v1.1 验证后再抬升至 37"；
  - §4"核心依赖候选清单"中的 DI 候选（Hilt 或手动 DI）→ **已裁决为手动 DI，见 ADR-004**；网络候选"OkHttp（+ 可选 Retrofit 或 kotlinx.serialization 手写解析）"→ **已裁决为 OkHttp + kotlinx.serialization，不引入 Retrofit，见 ADR-005**；
  - §4 未提及但需补充的是：**Material Icons 库已弃用并从 Material 3 移除**，图标统一走 Lucide（ADR-002）。
- 上述同步动作属团队文档一致性维护，建议在汇总三份文档时一并执行；本 ADR 生效日期起，以 ADR + 架构文档 §4.1 为版本事实源。

### 环境安装清单（修订后）

- Android Studio Quail（2026.1.x stable）
- Android SDK Platform 37（Android 17）+ Build-Tools 37.x
- JDK：AS 内置 JetBrains Runtime（满足 AGP 9 的 17+ 要求）
- 无需单独安装 Gradle（wrapper 锚定）；首次构建时核对 KSP 与 Kotlin 2.3.21 的配对版本
