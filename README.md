# 西工程大课表（XpuTimetable）

面向西安工程大学学生的课程表 App。只做一件事：**把教务系统的课表搬进手机，看得清、改得动、不打扰**。

没有账号、没有云端、没有后台服务。课表全在你自己手机里，登录教务系统的密码既不会存进本应用，也不会被上传到任何服务器。

---

## 功能

**课表**
- 周视图，周一到周日横向排布；支持上一周、下一周、回到本周
- 节次与时间轴对应，晚间课程（第 10 节及以后）时间照常显示
- 课程按自己的颜色区分，同一时段冲突的课程合并成一组展示
- 桌面小组件：一眼看到今天有哪些课

**导入**
- 打开教务系统登录页，登录后自动抓取课表
- 也可以导入此前导出的 JSON 文件，或扫描二维码
- 手动增删课程随时可用

**编辑**
- 点任意课程可看详情（节次、时间、地点、备注）
- 新增课程可自己配色，内置 12 色预设，也能用取色盘从满色域里挑任意颜色
- 支持单周 / 双周 / 全部 三种显示范围

**待办**
- 清单 + 条目两级结构，点标题可就地改名
- 勾选时从左到右划掉；一组全部勾完自动折叠并归入「已完成」
- 勾完最后一项会撒一把纸片彩带，等彩带放完才收进「已完成」
- 长按标题删整张清单，长按条目删单条（都有二次确认，删了不可撤销）

**外观**
- 深色模式跟随系统
- 可自定义背景图：作用范围可多选（全局 / 课表 / 我的 / 便签），背景浓度与卡片透明度都能调
- 卡片是半透明的玻璃面，颜色跟着背景图主色走

**其他**
- 设置在「我的」里：调整学期起始日、切换是否显示老师姓名

## 快速开始

### 使用现成版本
从 Releases 页下载 APK 安装即可，支持 Android 8.0（API 26）及以上。

### 自己构建
需要 JDK 21、Android SDK、Gradle 9，然后执行：

```bash
./gradlew assembleRelease
```

产物在 `app/build/outputs/apk/release/app-release.apk`。

### 跑测试

```bash
./gradlew testDebugUnitTest
```

## 数据安全

这是这个项目最在意的边界，三条都不打折：

1. **无后端**。课表与待办都落在本机 SQLite，没有服务器，也没有接口。
2. **凭据零存储**。教务系统的登录只发生在内置浏览器里，密码不写进数据库、不写进日志、不上传。
3. **导出权在你**。想换手机或备份，可以导出 JSON 或生成二维码，随时带走课表。待办暂不支持导出。

删除 App 即删除全部数据，无回收站。

## 项目结构

单模块 + 按职责分包：

```
ui/          界面（Compose）：课表、待办、编辑、设置、导入、分享、背景
domain/      领域模型与纯函数规则（不依赖 Android）
data/        数据层：数据库、仓储、导入导出解析、偏好存储
widget/      桌面小组件
docs/        设计文档：需求、架构、UI 规范、规格契约、验收报告
```

界面用 Jetpack Compose + Material 3，数据用 Room，图标用 Lucide。

完整的设计与规格说明见 `docs/` 目录：

- `docs/02-PRD产品需求文档.md` — 需求与取舍
- `docs/03-技术架构文档.md` — 分层、依赖、数据模型
- `docs/04-UIUX设计文档.md` — 界面与交互约定
- `docs/05-Spec-规格契约.md` — 开发约束与门禁
- `docs/verify/` — 各里程碑的验收报告
